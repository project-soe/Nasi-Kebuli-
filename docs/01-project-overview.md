# 01 - Gambaran Proyek

**Kebuli Ikhsan** - website pemesanan nasi kebuli ayam dan kambing khas Timur Tengah.

## Fitur pelanggan
- Animasi pembuka singkat, menu dengan foto/harga/deskripsi, keranjang animatif
- Ringkasan pesanan langsung, status toko buka/tutup
- Checkout, pesan WhatsApp tersusun otomatis, pantau status pesanan

## Fitur pemilik (admin)
- Login, daftar pesanan langsung (terima/tolak/proses/selesai), kelola menu, pengaturan toko, saklar buka/tutup

## Identitas visual
- Warna: cokelat gelap `#2b1810`, emas rempah `#c9a24b`, krem nasi `#f6ebd3`, merah bata `#a8472f`
- Font: Playfair Display (judul), Poppins (teks)
- Semua nilai desain ada di `public/css/tokens.css`

## Teknologi
HTML, CSS, JavaScript (ES modules) tanpa build tool. Database dan login: Firebase (Firestore + Authentication).
Hosting: GitHub Pages.
